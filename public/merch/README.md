# Merch assets

The source photographs, print-mask layer, Pink October cutouts and brand artwork
are supplied by the owner from the sibling `cssmerch` project. `tees/` contains
web-sized front/back derivatives of its photographic renderer, not 3D textures.
The existing GLB and its clean textures remain under `css_shirt_3dmodel/`.

Regenerate photographic derivatives with `node tools/prepare-merch.mjs`.
